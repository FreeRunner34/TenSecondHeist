# Asset record

The app icon and four audio files are original assets generated for Ten Second Heist by `tools/generate_assets.py`. Graphics are drawn from shapes and lettering rendered with DejaVu Sans Bold. The font file is not shipped; the local `fonts-dejavu-core` package records the Bitstream Vera license for the font and public-domain DejaVu changes in `/usr/share/doc/fonts-dejavu-core/copyright`. The sound cues and ambient music are synthesized mathematically; no recorded music, stock imagery, or third-party sprites are used.

SwiftUI draws the rest of the interface and floor plans from code and authored level geometry. SF Symbols are used through Apple's system framework in the iOS app.
